# Golf

A small grid-based golf game built with Python and tkinter.

Roll a die, pick one of 8 directions, and draw your shot across the course. Get the ball in the hole in as few strokes as possible.

## About

Inspired by [Paper Apps™ GOLF](https://gladdendesign.com/products/paper-apps-golf) by Gladden Design ([video](https://www.youtube.com/watch?v=q-WOSGi2je8)).

This project was mostly an excuse to practice:

- Basic Python
- Structuring a small project
- Building a UI with tkinter

## Running it

Requires Python 3 (tkinter is included with most Python installs).

```bash
git clone https://github.com/NicolasBerthiaume/simple-golf-game.git
cd simple-golf-game
python3 golf.py
```
